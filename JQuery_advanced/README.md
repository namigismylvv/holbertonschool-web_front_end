# JQuery Advanced Exercises

This repository includes a collection of practical exercises designed to explore advanced JQuery features.  
Each exercise is implemented in a separate HTML file and focuses on a specific concept.

## 🧩 Tasks Overview

### Task 0  
**File:** `0-index.html`  
**Description:** Checks if JQuery is properly loaded in the page.

### Task 1  
**File:** `1-index.html`  
**Description:** Appends a paragraph containing Lorem Ipsum text to the body.

### Task 2  
**File:** `2-index.html`  
**Description:** Creates a family tree table and appends it to the document.

### Task 3  
**File:** `3-index.html`  
**Description:** Builds the same family tree using JQuery functions.

### Task 4  
**File:** `4-index.html`  
**Description:** Replaces the existing family tree table with updated data.

### Task 5  
**File:** `5-index.html`  
**Description:** Allows adding and removing members in the family tree.

### Task 6  
**File:** `6-index.html`  
**Description:** Adds a form to insert new family members before or after existing ones.

### Task 7  
**File:** `7-index.html`  
**Description:** Implements a search form to query Wikipedia and display the results.

### Task 8  
**File:** `8-index.html`  
**Description:** Adds pagination to the Wikipedia search results.

### Task 9  
**File:** `9-index.html`  
**Description:** Displays a loading indicator while fetching Wikipedia results, with pagination support.

### Task 10  
**File:** `10-index.html`  
**Description:** Fetches and lists posts from a local JSON server.

### Task 11  
**File:** `11-index.html`  
**Description:** Another variation of listing posts from a local JSON server.

---

## ⚙️ Setup Instructions

For tasks that require backend data, a local JSON server must be running.

Install dependencies:
```bash
npm install
npx json-server --watch db.json --port 3000
