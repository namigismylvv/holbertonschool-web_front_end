# Holberton - Web Stack - Bootstrap

This project demonstrates the use of the **Bootstrap 4** framework to build responsive and styled web pages.  
Each file showcases different Bootstrap components and utilities, gradually covering more advanced layouts and interactive features.

---

## 🚀 Project Overview
The repository contains **8 HTML files** (plus some CSS customization).  
The goal is to practice using Bootstrap’s grid system, utilities, components, and JavaScript features such as modals, tabs, and collapses.

---

## 📂 File Descriptions

### 1. Basic Container (`0-index.html`)
- Demonstrates the use of a custom container (`.my-container`) with a background color.
- Includes headings, paragraphs, and nested unordered lists.
- Focuses on **basic HTML structure with Bootstrap stylesheet included**.

---

### 2. Grid System and Responsive Layout (`1-index.html`)
- Uses **Bootstrap grid classes** (`.container`, `.row`, `.col-*`).
- Demonstrates responsive column layouts.
- Shows how to manage padding and spacing with Bootstrap utilities.

---

### 3. Images and Styling (`2-index.html`)
- Demonstrates **Bootstrap’s image utilities**:
  - `.img-fluid` for responsive images.
  - `.rounded` and `.rounded-circle` for styled borders.
  - `.img-thumbnail` for framed images.
- Focuses on responsive media content.

---

### 4. Buttons and Utilities (`3-index.html`)
- Demonstrates **Bootstrap button styles**:
  - `.btn-primary`, `.btn-secondary`, `.btn-success`, etc.
  - `.btn-lg`, `.btn-sm` size variations.
  - `.btn-block` for full-width buttons.
- Covers **spacing and typography utilities**.

---

### 5. Cards and Modal (`4-index.html`)
- Implements **Bootstrap cards** with:
  - Headers, footers, body text, and images.
  - `.h-100` to keep cards equal height.
- Includes a **modal component** triggered by "Play with" buttons.
- Modal contains descriptive text and a **login form** with inputs and a submit button.

---

### 6. Tabs and Collapse (`5-index.html`)
- Uses **Bootstrap nav tabs** (`.nav-tabs`) to switch between content.
- First tab: *Introduction* with paragraphs about Bob Dylan.
- Second tab: *Discography* with an interactive **collapse list** for each album.
- Demonstrates combining multiple Bootstrap components (tabs + collapse).

---

### 7. Pricing Page (`6-index.html` and `6-styles.css`)
- A full **pricing layout** inspired by Bootstrap examples:
  - Responsive **navbar** with navigation links and a signup button.
  - **Pricing header** introducing the plans.
  - **Card deck** for Free, Pro, and Enterprise plans.
  - **Custom footer** with multiple columns of links.
- Custom styling in `6-styles.css`:
  - Modified `.btn-primary` and `.btn-outline-primary` colors.
  - Customized `.card`, `.card-header`, `.card-footer` with borders and rounded corners.
  - Consistent color scheme (`#e0003c` red theme).

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **Bootstrap 4.4.1**
- **Custom CSS** for overriding Bootstrap defaults
