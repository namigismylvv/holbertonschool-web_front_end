# HTML - CSS accessibility

This project follows the **Web Content Accessibility Guidelines (WCAG)** to ensure that the website is usable by everyone, including people with disabilities.

## Levels of Conformance

- **Level A** (Minimum):  
  Basic accessibility features implemented (e.g., `alt` attributes on images, form labels, semantic HTML).

- **Level AA** (Recommended):  
  Enhanced accessibility (e.g., sufficient color contrast, full keyboard navigation, resizable text without loss of content).

- **Level AAA** (Maximum):  
  The highest accessibility standard (e.g., sign language interpretation for videos, enhanced readability).  
  *Note: Achieving full AAA compliance may not always be practical for all content.*

## Implemented Practices in This Project

- Semantic HTML structure (`header`, `main`, `footer`, `nav`, etc.)
- Meaningful `alt` text for all images
- Labels and instructions for all form fields
- Color contrast ratio following WCAG 2.1 AA requirements
- Skip links for keyboard users
- Focus indicators visible on interactive elements
- ARIA attributes where necessary
-Using developer tools extensions (HeadingsMap,Landmark Navigation,axe Devtools)
